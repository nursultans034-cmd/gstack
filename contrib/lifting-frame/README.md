# Расчёт подъёмной рамы

Программа считает подъёмную раму (спредер-раму) по данным груза. Схема: крюк → верхние ветви →
плоская рама из труб → вертикальные нижние стропы → точки груза. Нормы: DNV-ST-N001, AISC ASD 9-е изд., S355.

- `frame-calc.js` — расчётное ядро (чистые функции, без интерфейса).
- `index.html` — интерфейс: ввод данных, план и вид сбоку, таблицы проверок, отчёт.
- `verify.mjs` — сверка ядра с расчётной запиской буя TR1224: `node contrib/lifting-frame/verify.mjs`.

Локальный запуск: `cd contrib/lifting-frame && python3 -m http.server`, затем открыть `http://localhost:8000`
(ES-модуль не загружается по `file://`).

Что считается: доли нагрузки по ЦТ (3 точки — статически определимо; 4 и более — решение с минимальной
нормой и SKL), статика на точки груза против WLL, высота крюка по минимальному углу ветви, натяжения
ветвей, усилия в стержнях рамы (плоская ферма, метод перемещений), проверки стержней (H1-1, H1-2, H1-3,
гибкость, D/t, прогиб), автоподбор трубы, верхние проушины (растяжение, срез, смятие, корень из плоскости),
запас стропов и скоб, нагрузка на кран и высота крюка над низом груза.

Не считается: узлы рамы, сварные швы, эксцентриситет в узлах (нужен FEA), крепление на переход.
